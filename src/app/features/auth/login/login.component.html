El origen de Amati

🇲🇽

Náhuatl

Se traduce generalmente como "disfrutar" (gozar o deleitarse), o como "gustar" (tener el gusto por algo). También se utiliza de manera interrogativa como "quién sabe" (para expresar duda).

🇮🇹

Italiano

Es la forma imperativa del verbo amare (ámate / quiérete): "Ámate a ti mismo". También es el plural masculino de "amados" o "queridos".
